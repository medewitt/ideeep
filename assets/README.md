# Image assets

This file catalogs the images in `assets/` that are **not** generated by the
Python figure pipeline, so it's clear what each one is and where it came from.

## What is and isn't generated

| Tree | Generated? | Source |
| --- | --- | --- |
| `assets/figures/*.svg` | Yes — Python (matplotlib) | `figures/<name>.py`; rebuild with `just figures` |
| `assets/cards/*.svg` | Yes — Python (matplotlib) | `figures/_card_motifs.py`; abstract homepage card backgrounds |
| `assets/ideep_logo.svg`, `assets/wake_biology_logo.svg` | Yes — LaTeX (not Python) | `ideep_logo.tex` / `wake_biology_logo.tex`; rebuild with `just ideep-logo` / `just logo` |
| Everything else below | No — hand-drawn, downloaded, or photographed | Documented in this file |

The generated trees are self-documenting through their source scripts, so they
are not listed individually here. Everything cataloged below is a committed,
non-Python asset that has no generating script in the repo.

## Scientific illustrations (NIH BioArt Source)

Flat vector illustrations from the [NIH BioArt Source](https://bioart.niaid.nih.gov/)
(NIAID). Their filenames follow the BioArt naming convention. Where the SVG
still carries its `<metadata>` block, it records **creator: Ryan Kissinger**,
**credit: Courtesy of NIAID**, and **license: Public Domain**; a few files have
had that metadata stripped, so their provenance is inferred from the naming
convention and matching style. None of these are wired into a page yet — they
are a stock library kept on hand for illustrating diagnostics, epidemiology, and
methods pages.

## Provenance summary

- **NIH BioArt illustrations** — Public Domain, courtesy of NIAID
  (bioart.niaid.nih.gov). Free to use; attribution to NIAID is courteous.
- **Photographs** — no license metadata is embedded. Field, landscape, and
  portrait photos are by Michael E. DeWitt; the whiteboard photo is courtesy of
  Epistorm; the two historical scans are public domain by age. Verify rights
  before reusing outside this site.
- **Esri aerial imagery** (`eden-terrace-deck-*.jpg`) — Esri World Imagery
  (Wayback); Source: Esri, Maxar, Earthstar Geographics, and the GIS User
  Community. Included as static screen captures for non-commercial educational
  illustration under the ArcGIS Online terms of use, which permit screen
  captures with attribution for non-commercial use. Do not reuse commercially or
  redistribute the tiles.
- **Logos / brand assets** — Wake Forest University marks are used under the
  program's affiliation; follow WFU brand guidelines for any new use.
