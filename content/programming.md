# Programming & Computing

There are some great general resources for learning how to use plain text environments for scientific computing more generally.

## Topics

Bite-sized guides to good programming practice and the everyday tools of
reproducible scientific computing, with examples in R, Python, and Julia.

- [Data Representation & File Formats](programming/data-representation-and-formats.md) — encodings, CSV pitfalls, tidy/relational data, SQL, and FASTA/VCF

- [Parallelism & Concurrency](programming/parallelism-and-concurrency.md) — cores vs threads, race conditions, and thread oversubscription
